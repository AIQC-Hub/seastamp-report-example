# seastamp: stamped data summary reports

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24093929.svg)](https://doi.org/10.5281/zenodo.24093929)

A static web site of summary reports for data stamped by seastamp, one page per
(region, product) unit, generated by the
[`seastamp`](https://github.com/AIQC-Hub/seastamp) helper script
`summary_site.sh` (built with [mdBook](https://rust-lang.github.io/mdBook/)).

This directory is the built site: open `index.html` locally, or publish
it as-is with GitHub Pages (a `.nojekyll` is included).

Regions in this build: arctic baltic mediterranean.

Generated on 2026-11-12.
